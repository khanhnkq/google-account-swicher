# Privacy Policy for Fast Google Account Switcher

**Last updated:** October 1, 2026

## 1. Overview
Fast Google Account Switcher ("the Extension") is an open-source browser extension designed to help users switch between logged-in Google accounts by updating URL parameters (`/u/0/`, `/u/1/`, `authuser=X`).

## 2. Information Collection and Use
* **No Personal Data Collected:** The Extension does not collect, store, transmit, or sell any personal data, browsing history, account credentials, or telemetry.
* **Local Execution Only:** All URL modifications and keyboard shortcut handling occur entirely locally within your browser. No external servers or analytics services are contacted.

## 3. Permissions Justification
* **`tabs` permission:** Required solely to read the current active tab's URL (to determine if you are on a Google service like Gmail or Drive) and update the URL with the desired account index (`/u/0/` -> `/u/1/`). No tab data is recorded or stored.

## 4. Third-Party Services
The Extension does not use third-party libraries, tracking pixels, or remote scripts.

## 5. Contact
If you have questions regarding this privacy policy, please contact the developer via GitHub.
